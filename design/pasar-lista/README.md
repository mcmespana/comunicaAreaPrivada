# Mockups de Pasar Lista

Ficheros fuente del canvas de diseño (Claude Design). Cada `.dc.html` es una
pantalla; `canvas.json` los coloca y añade las notas.

| Fichero | Pantalla |
|---|---|
| `Main.dc.html` | Home de Pasar Lista (atajo a la sesión de hoy + listas pendientes) |
| `Grupos.dc.html` | Navegación etapa → grupo |
| `Marcar.dc.html` | Marcado de asistencia (interactivo) |
| `Ficha.dc.html` | Ficha del participante y contacto con la familia |
| `Resumen.dc.html` | Resumen de grupos para coordinación |

Los colores, radios y sombras salen de `css/custom-style.css`; la tipografía es
Inter, la del área privada.

El diseño funcional y las decisiones abiertas están en
[`docs/comunica/PASAR-LISTA.md`](../../docs/comunica/PASAR-LISTA.md).

`pasar-lista-mcm.html` es el canvas ya montado (generado, no se edita a mano).
